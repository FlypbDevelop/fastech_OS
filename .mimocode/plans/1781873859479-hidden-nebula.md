# Plano: Menu Lateral com NavigationRail

## Contexto

O projeto usa botões de navegação no topo (barra horizontal). O objetivo é migrar para um **NavigationRail** lateral esquerdo, estilo dashboard profissional, com destaque visual na aba ativa.

## Layout Atual → Novo Layout

### Atual
```
┌──────────────────────────────────────────┐
│  Header (azul, logo + titulo)            │
├──────────────────────────────────────────┤
│  [Dashboard] [Clientes] [Equipamentos]   │  ← nav_bar horizontal
│  [Movimentações] [Consultas] [Config]    │
├──────────────────────────────────────────┤
│  content_container                       │
└──────────────────────────────────────────┘
```

### Novo
```
┌────────┬─────────────────────────────────┐
│        │  Header (azul, logo + titulo)   │
│  Nav   ├─────────────────────────────────┤
│  Rail  │                                 │
│        │  content_container              │
│ 🏠 Dash│                                 │
│ 👥 Cli │                                 │
│ 📦 Equi│                                 │
│ 🔄 Mov │                                 │
│ 🔍 Cons│                                 │
│ ⚙️ Conf│                                 │
└────────┴─────────────────────────────────┘
```

## Arquivo a Modificar

### `app.py` (único arquivo alterado)

#### 1. Adicionar estado de aba ativa

```python
self.aba_ativa = "dashboard"
```

#### 2. Criar NavigationRail

```python
self.nav_rail = ft.NavigationRail(
    selected_index=0,
    label_type=ft.NavigationRailLabelType.ALL,
    min_width=80,
    min_extended_width=200,
    destinations=[
        ft.NavigationRailDestination(icon="🏠", label="Dashboard"),
        ft.NavigationRailDestination(icon="👥", label="Clientes"),
        ft.NavigationRailDestination(icon="📦", label="Equipamentos"),
        ft.NavigationRailDestination(icon="🔄", label="Movimentações"),
        ft.NavigationRailDestination(icon="🔍", label="Consultas"),
        ft.NavigationRailDestination(icon="⚙️", label="Configurações"),
    ],
    on_change=self.on_nav_change,
)
```

#### 3. Handler de navegação

```python
def on_nav_change(self, e):
    index = e.control.selected_index
    abas = ["dashboard", "clientes", "equipamentos", "movimentacoes", "consultas", "configuracoes"]
    conteudos = [
        self.dashboard_content,
        self.clientes_content,
        self.equipamentos_content,
        self.movimentacoes_content,
        self.consultas_content,
        self.configuracoes_content,
    ]
    self.aba_ativa = abas[index]
    self.content_container.content = conteudos[index]
    self.page.update()
```

#### 4. Reestruturar layout principal

De `ft.Column([header, nav_bar, content])` para:
```python
self.page.add(
    ft.Row(
        [
            self.nav_rail,                    # Sidebar esquerda
            ft.Column(
                [
                    header,                    # Header no topo
                    self.content_container,    # Conteúdo
                ],
                spacing=0,
                expand=True,
            ),
        ],
        spacing=0,
        expand=True,
    )
)
```

#### 5. Remover nav_bar antiga

Remover o bloco inteiro do `nav_bar` (ft.Container com ft.Row de FilledButtons).

#### 6. Atualizar funções de navegação

As funções `ir_para_dashboard`, `ir_para_clientes`, etc. podem ser simplificadas ou removidas (o `on_change` do NavigationRail cuida disso).

## Impacto

- **Apenas `app.py` é alterado** — nenhuma aba individual (gui/*.py) precisa de mudanças
- O `content_container` continua funcionando da mesma forma
- O header se adapta automaticamente (ocupa largura restante)
