# Plano: Atualização e Limpeza da Documentação

## Contexto

O projeto FastTech Control possui documentação fragmentada e com excesso de changelogs. O objetivo é criar:
1. **README.md simples** na raiz — visão geral para qualquer pessoa
2. **docs/DOCUMENTACAO_TECNICA.md completa** — referência para desenvolvedores e assistentes de IA

## Problemas Identificados

1. **Duplicação**: README.md e DOCUMENTACAO_TECNICA.md cobrem os mesmos tópicos (~70%)
2. **Changelogs obsoletos**: 4 arquivos em docs/ (1.119 linhas) com mudanças já no git
3. **Versão inconsistente**: README referencia Flet 0.80.5, requirements.txt declara >=0.21.0
4. **Referência desatualizada**: README menciona .kiro/ que não existe mais
5. **Artefato de sessão**: .summary.md não é documentação do projeto

## Estrutura Final

```
fastech_OS/
├── README.md                        # Simples — visão geral do projeto
├── docs/
│   └── DOCUMENTACAO_TECNICA.md      # Completa — para devs e IAs
├── gui/                             # Interface gráfica (13 arquivos)
├── utils/                           # Utilitários
├── app.py                           # Aplicação principal
├── database.py                      # Camada de dados
├── models.py                        # Modelos e constantes
├── requirements.txt                 # Dependências
└── config.json                      # Configurações do usuário
```
